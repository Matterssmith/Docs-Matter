# Docs-Matter — documentación e índice del ecosistema

- Mantener `README.md` como índice actualizado.
- Referenciar iniciativas a sus repositorios responsables y distinguir ideas de funciones desplegadas.
- Cambios de propuesta: documentar fuente (petición del propietario), fecha, estado real, riesgos, pendientes y prueba de publicación.
- No prometer envíos sin costo universales, beneficios fiscales por cruces entre estados, garantía vitalicia sin cobertura o generadores con energía neta ilimitada.
- No publicar datos privados de usuarios, seriales reales, tokens ni acceso a Vault.
- Revisar todos los README existentes antes de cada commit y actualizar `docs/WORK_CONTINUITY.md`.
